# Plugin Store promo images

Marketing images for the Fold listing on the Craft Plugin Store.

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `fold-promo-N.jpg`, 1920×1080, JPEG quality 90 (rendered at 2× in
headless Chrome, then downsampled and converted in one `sips` pass; the intermediate PNG is
deleted). Promos are JPEG, never PNG — `out/` should only ever hold `.jpg` files.

## Screenshots

All shots are real, from the plugin-testing harness. Seed the demo first:

```bash
cd ~/Sites/plugin-testing
ddev exec php /var/www/craft-fold/tests/manual/seed-demo.php
```

That creates the "Tidewater Chandlery" group (fifteen shops with hand-typed coordinates — no
geocoder is called), links nine to Commerce inventory locations with stock of one variant, writes
geocode-cache rows for the demo search terms and some search-log rows, and copies the demo
templates from `tests/manual/templates/` into the harness. Then:

- `/fold-demo?q=Wilmington%2C%20NC&radius=100` → `fold-locator.png`
- `/fold-demo/stock` → `fold-in-stock.png`
- `/chandlery/wilmington-riverfront` → `fold-store-page.png`
- CP `Fold → Locations → Tidewater Chandlery` → `fold-index.png`
- CP `Fold → Searches`, the "found nothing" card → `fold-searches.png`

Front-end shots were taken with headless Chrome at 2× (`--ignore-certificate-errors`); CP shots
with Playwright, logged in, with the harness's other plugins' floating widgets removed from the
DOM before capture.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. Accent `#753fa0`,
Jersey 20 for display, Inter for body.

`assets/` holds the fonts and three icon files:

- `icon.svg` — the app icon (white crane on the purple tile), for the cover and footer. Copy it
  from `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the crane only, from `../src/icon-mask.svg` filled white. The tile is
  stripped because at watermark scale it reads as a hard-edged box across every slide.
- `icon-source.jpg` — the original source artwork. Not used by the deck.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
